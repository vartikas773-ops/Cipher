# 🦜🔗 Cipher

Chat with your PDFs using a hosted LLM. Upload a document, and ask questions about it in plain English — answers are generated by [Groq](https://groq.com/)'s free hosted inference API, with document embedding and similarity search running locally.

## ✨ Features

- 📄 **Upload a PDF** and ask natural-language questions about its contents
- 🔍 **Retrieval-augmented generation (RAG)** — answers are grounded in the actual document via similarity search, with the matching passages shown alongside each response
- ⚡ **Powered by Groq** (e.g. `llama-3.1-8b-instant`) — fast, free-tier hosted inference, no local model server to run or maintain
- 🧠 **Local embeddings** via HuggingFace `sentence-transformers` — document indexing never leaves your machine/deployment
- 💬 **Persistent chat interface** with history, avatars, and a "thinking..." spinner while the model responds
- 🟢 **Live connection status** — the sidebar checks that a Groq API key is configured and shows a green/red status pill, so a missing or invalid key shows a plain-English message instead of a raw traceback
- ⚙️ **Configurable at runtime** — set your Groq API key and model name directly from the sidebar, no code changes needed

## 🛠️ Tech stack

- [Streamlit](https://streamlit.io/) — UI
- [LangChain](https://www.langchain.com/) (`langchain`, `langchain-community`, `langchain-groq`) — RAG orchestration (`RetrievalQA`)
- [Groq](https://groq.com/) — hosted LLM inference
- [Chroma](https://www.trychroma.com/) — vector store
- [HuggingFace `sentence-transformers`](https://www.sbert.net/) (`all-MiniLM-L6-v2`) — embeddings
- [PyTorch](https://pytorch.org/) — required by `sentence-transformers`
- `PyPDFLoader` (via `langchain-community`) — PDF parsing
- `python-dotenv` — local environment variable loading
- `Pillow` — optional sidebar logo rendering

## 🚀 Running locally

```
git clone https://github.com/vartikas773-ops/Cipher.git
cd Cipher
pip install -r requirements.txt
```

Get a free Groq API key at [console.groq.com/keys](https://console.groq.com/keys) (no credit card required), then either:

- Create a `.env` file in the project root with:
  ```
  GROQ_API_KEY=gsk_your_key_here
  ```
- Or paste the key directly into the app's sidebar under **Connection settings** once it's running.

Then start the app:

```
streamlit run app.py
```

By default the model is `llama-3.1-8b-instant`. You can change this live from the sidebar.

An optional `my_logo.png` in the project root will be shown at the top of the sidebar if present.


## 📌 Notes

- Uploaded PDFs are written to a temporary directory during processing and are not persisted between sessions.
- Document content and questions are sent to Groq's API for answer generation; embeddings and similarity search happen locally and are never sent anywhere.
- Groq's free tier has rate limits (requests/tokens per minute) — fine for personal use and demos, not intended for high-traffic production use.
